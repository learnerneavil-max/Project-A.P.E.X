# The Architect's OS

Most people operate as **End Users** of reality. They interact with the glossy user interface of life, follow the rules they are given, and get frustrated when the system breaks.

This repository is for those who want to become **Developers**. 

It is an open-source manual for reverse-engineering learning, human behavior, strategy, and systems. You are no longer memorizing facts; you are extracting the underlying source code of how the world actually works.

To view the live documentation, run `npm start` or visit the hosted GitHub Pages link.
