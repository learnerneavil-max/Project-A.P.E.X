# The Four Levels of Pattern Recognition

How to push raw information into automated mastery:

1. **Compression (Chunking):** Grouping isolated data points into a single, meaningful block to bypass working memory limits.
2. **Semantic Search (Intuition):** Using tiny details as search terms to instantly query your mental library without conscious thought.
3. **Templates (Mental Models):** Building a reusable skeleton for solving recurring problems so you never start from zero.
4. **Pattern Transfer (Arbitrage):** Taking a template from one domain (e.g., Chess) and applying its physics to an unrelated domain (e.g., Business).
