# The Architect's OS

You do not lack knowledge; you lack a parser. This documentation is designed to upgrade your cognitive processing from an End User to a Systems Architect.

## The 3-Step Architect's Loop

Whenever you face a problem, do not look for a productivity hack. Run this loop:

1. **See the Game (Sensemaking):** Stop looking at surface details. Step back and ask: *"What is the hidden rule or feedback loop driving this situation?"*
2. **Find the Lever (First Principles):** Find the single smallest thing that controls the outcome. Ask: *"If I strip away the noise, what is the core mechanism here?"*
3. **Rig the Board (Choice Architecture):** Stop relying on willpower. Ask: *"How can I change the environment or incentives so the outcome I want happens automatically?"*
