# Protecting the Machine (Cognitive Bandwidth)

Your brain is a biological engine with finite RAM. 

### Core Operating Rules:
* **The Zeigarnik Effect:** Unfinished tasks drain background energy. Batch tasks and write them down to clear open loops.
* **Monotasking:** Multitasking is a myth; it is just rapid context-switching that degrades processing power.
* **Guard the Inputs:** Do not start your day with email. That is allowing other people's emergencies to program your neural pathways.
